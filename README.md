# Qué es un agente de código y cómo trabajar con él

Código del tutorial de [Código Fácil](https://www.codigofacil.es/aprender/que-es-un-agente-de-codigo): tu primera página web creada con un agente de código (Claude Code), siguiendo el ciclo **pedir → revisar → probar → guardar**.

## Qué hay aquí

| Archivo | Qué es |
|---|---|
| [`index.html`](index.html) | La página que creó el agente: tu nombre, una frase sobre ti y tres enlaces, con modo oscuro y adaptada al móvil |
| [`CLAUDE.md`](CLAUDE.md) | El archivo de instrucciones del proyecto: lo lee el agente al empezar cada sesión |
| [`sesion-claude-code/`](sesion-claude-code/) | La sesión real de Claude Code que aparece en el vídeo: prompt, plan, acción y resumen |

## Pruébalo

1. Descarga el repositorio (botón **Code → Download ZIP**) o clónalo:
   ```bash
   git clone https://github.com/codigo-facil-es/que-es-un-agente-de-codigo.git
   ```
2. Abre `index.html` en tu navegador (doble clic).
3. Cambia `Tu Nombre`, la frase y `tu_usuario` en los enlaces por tus datos.
